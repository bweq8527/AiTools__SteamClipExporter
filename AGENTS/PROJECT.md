## 当前用途和使用场景（代码事实）

这是以 Windows 本地桌面／本地浏览器使用为主的 Steam 录像导出工具。用户指定本地素材库和可选导出库，扫描录像目录，浏览缩略图或短预览，选择录像加入队列，输出 `<cid>.mp4`，查看任务进度和日志。具体业务流程见 [DATA_FLOW.md](DATA_FLOW.md)。

前后端在文件和职责上分开，运行时由同一个 Flask 服务提供静态前端及 API；桌面入口用 pywebview 装载本地网页。不存在已发现的独立前端构建服务。技术事实见 [ARCHITECTURE.md](ARCHITECTURE.md)。
